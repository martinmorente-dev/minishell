# Minishell - TurtleShell

*This project has been created as part of the 42 curriculum by alberome & Martin Morente Vargas.*

## Description

**Minishell** (also known as **TurtleShell**) is an educational implementation of an interactive Unix shell developed in C. The project aims to understand the fundamental concepts of how command interpreters work, including:

- **Command parsing**: Lexical and syntactic analysis of command lines
- **Process execution**: Creation and management of child processes using `fork` and `exec`
- **Pipelines**: Connecting multiple commands through pipes (`|`)
- **Redirections**: Handling standard input/output (`<`, `>`, `>>`, `<<`)
- **Environment variables**: Managing shell environment
- **Built-in commands**: Implementation of internal commands (`cd`, `echo`, `pwd`, `export`, `unset`, `env`, `exit`)
- **Signal handling**: Managing user interruptions (Ctrl+C, Ctrl+D)
- **Variable expansion**: Interpretation of environment variables in commands
- **Wildcard expansion**: Support for wildcards (`*`, `?`)

The goal is to provide a functional and educational experience that helps understand how bash and other shells handle user interaction and program execution.

## Instructions

### Compilation

To compile the project, simply run:

```bash
make
```

This command:
- Compiles the libft library (standard C utilities)
- Compiles all source files of the project
- Links everything into the `minishell` executable

#### Makefile Options

```bash
make clean      # Removes compiled objects
make fclean     # Removes objects and executable
make re         # Recompiles the project from scratch
```

### Execution

Once compiled, run the interactive shell with:

```bash
./minishell
```

This will open an interactive prompt where you can type commands just like you would in bash:

```bash
$ ./minishell
turtleshell> ls -la
turtleshell> echo "Hello World"
turtleshell> cat file.txt | grep "pattern"
turtleshell> exit
```

### Usage Examples

#### Basic Commands
```bash
turtleshell> echo "Hello!"
Hello!

turtleshell> pwd
/home/user/minishell

turtleshell> ls -l *.c
```

#### Pipelines
```bash
turtleshell> cat file.txt | grep "word" | wc -l
```

#### Redirections
```bash
turtleshell> echo "content" > file.txt
turtleshell> cat < file.txt
turtleshell> echo "more content" >> file.txt

# Heredoc (multiline input)
turtleshell> cat << EOF
> line 1
> line 2
> EOF
```

#### Environment Variables
```bash
turtleshell> export VARIABLE="value"
turtleshell> echo $VARIABLE
value

turtleshell> env
```

#### Built-in Commands
```bash
turtleshell> cd /path/to/directory
turtleshell> pwd
/path/to/directory

turtleshell> unset VARIABLE
turtleshell> exit 0
```

### Requirements

- **C Compiler**: gcc or clang
- **GNU Readline**: Library for interactive command-line editing
- **Operating System**: Linux or macOS (Unix-like)

#### Dependencies Installation

**On Ubuntu/Debian:**
```bash
sudo apt-get install build-essential libreadline-dev
```

**On macOS (with Homebrew):**
```bash
brew install readline
```

## Project Structure

```
minishell/
├── Makefile              # Build system
├── inc/
│   ├── minishell.h      # Main definitions and structures
│   └── libft.h          # libft header
├── lib/
│   └── libft/           # C utilities library
├── src/
│   ├── main.c           # Main entry point
│   ├── script_prep.c    # Script preparation
│   ├── script_run.c     # Script execution
│   ├── shell_loop.c     # Main shell loop
│   ├── signals.c        # Signal handling
│   ├── builtins/        # Built-in commands implementation
│   ├── env/             # Environment variables management
│   ├── exec/            # Command execution
│   ├── parser/          # Lexical and syntactic analysis
│   └── utils/           # Utilities and helper functions
└── objs/                # Compiled objects (generated by make)
```

### Key Components

- **Parser** (`src/parser/`): Converts strings into command structures
- **Executor** (`src/exec/`): Executes commands using `fork` and `exec`
- **Environment** (`src/env/`): Manages environment variables
- **Builtins** (`src/builtins/`): Implements internal shell commands

## Technical Decisions

### Memory Management
- A custom library (`libft`) is used for utility functions
- All dynamic allocations are carefully freed to prevent memory leaks

### Parsing
- Implementation of a lexer that tokenizes input
- Parser that builds a command tree structure (pipeline)
- Support for quoted strings, variable expansion, and wildcard expansion

### Signals
- Handling of `SIGINT` (Ctrl+C) for interactive behavior
- Different signal handling in interactive vs. non-interactive mode

### Redirections
- Implementation using file descriptors and `dup2`
- Support for heredoc with temporary files
